# WhatsApp Auto Message Sender 🚀

A simple and beginner-friendly Python project to send automated WhatsApp messages using `PyWhatKit`.

---

## 📌 Features

- Send WhatsApp messages automatically
- Clean and modular Python code
- Instant message sending
- Automatic browser tab closing
- Error handling included
- Easy to customize

---

## 🛠️ Tech Stack

- Python 3.x
- PyWhatKit
- PyAutoGUI

---

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/whatsapp-message-sender.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd whatsapp-message-sender
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python main.py
```

---

## 📦 requirements.txt

```txt
pywhatkit
pyautogui
```

---

## ⚠️ Important Notes

- Make sure you are logged into WhatsApp Web
- Keep your internet connection active
- Do not close the browser while the script is running
- Avoid moving the mouse/keyboard during automation

---

## 🐞 Common Errors

### ModuleNotFoundError

Install dependencies:

```bash
pip install pywhatkit pyautogui
```

### WhatsApp Web Not Opening

Make sure:
- Default browser is installed
- Internet connection is active
- WhatsApp Web is accessible
